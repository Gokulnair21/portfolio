## Intent

**Problem:** The project root has no application — the Actuator-themed portfolio cannot exist until an Angular v22 baseline is scaffolded with the project's idiom rules and a themed shell recruiters instantly recognize as a Spring Boot Actuator dashboard.

**Approach:** Scaffold Angular v22 (esbuild `@angular/build` builder, strict TS) into the project root, define design tokens (status palette, monospace stack, spacing) as CSS custom properties in one global stylesheet, and build the shell: a standalone OnPush root component rendering a themed header + panel area in hand-rolled CSS.

## Boundaries & Constraints

**Always:**
- Angular ^22 with the `@angular/build` (esbuild) builder; TypeScript ~6.0; strict mode on in all tsconfigs.
- All components standalone, signals-first, OnPush change detection, built-in control flow (`@if/@for`) where control flow is needed.
- Status palette (up green, degraded red, info blue), monospace font stack, and spacing scale live only as CSS custom properties in one global stylesheet (`src/styles.css`); every component references tokens only — including SVG stroke/fill attributes.
- Hand-rolled CSS only; styling is authored by hand in component/global stylesheets.

**Ask First:**
- Any deviation from Angular ^22 / TypeScript ~6.0 if the registry resolves differently.
- Adding any npm dependency beyond what `ng new` generates.

**Never:**
- No Angular Router import anywhere; no routing setup.
- No Tailwind, no UI/component library, no CSS framework.
- No NgModules; no non-standalone components.
- No raw color/spacing values outside token definitions.
- No tab/store logic (`ClusterStateService`, Story 1.2), no JSON hydration (`PortfolioDataLoader`, Story 1.3), no health metrics panel (Story 1.4).
- No git operations (init/commit) — the human owns version control.

## Code Map

Project root is greenfield — only `_bmad*/` and `.opencode/` metadata dirs exist. Everything below is created by this story:

- `package.json` -- generated by scaffold; scripts `start`/`build`; deps pinned to Angular ^22
- `angular.json` -- must use the `@angular/build:application` builder (esbuild)
- `tsconfig.json` (+ `.app.json`, `.spec.json`) -- `strict: true`
- `src/styles.css` -- single global stylesheet; defines ALL design tokens as CSS custom properties
- `src/app/app.ts|.html|.css` -- root shell component: standalone, OnPush, themed header + panel area
- `src/app/app.config.ts` -- minimal app config; no router provider
- `public/` -- static assets dir (later stories add `portfolio-data.json` here)

Token vocabulary for `styles.css`: `--status-up` (green), `--status-degraded` (red), `--status-info` (blue), monospace font stack var(s), spacing scale (e.g. `--space-1..8`). Names may be refined but semantics are fixed by the epic context.

Scaffold placement constraint: `ng new` refuses a non-empty directory. Generate into a temp dir with `npx -y @angular/cli@^22 new portfolio --style css --ssr false --skip-git --skip-tests false`, then move contents (including dotfiles) up into the project root before npm install.
