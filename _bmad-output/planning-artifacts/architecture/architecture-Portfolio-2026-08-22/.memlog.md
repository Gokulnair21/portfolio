- (constraint) PRD non-goals: no JVM backend, no real Kafka, no DB persistence, no auth — everything client-side simulated
- (constraint) Hosting: GitHub Pages, $0 budget, free APIs only (SM-3)
- (decision) [ADOPTED] Stack: Angular + TypeScript SPA deployed as static assets to GitHub Pages. Binds framework choice; prevents divergence toward vanilla HTML or React
- (decision) AD-1 State: single ClusterStateService exposing Angular signals (status, errorRate, logs[]); components derive via computed(). No NgRx/RxJS store. Binds all cross-panel state flow through one service; prevents ad-hoc per-component state copies diverging on outage state
- (decision) AD-2 Navigation: no Angular Router; tabs are signal-driven panel switching in a single-page dashboard shell. Binds navigation to in-app state; prevents GitHub Pages static-hosting refresh/deep-link breakage and router bundle overhead
- (decision) AD-3 Data: portfolio content lives in assets/portfolio-data.json fetched at runtime via HttpClient; components render from a typed interface over the parsed JSON. Binds content/code separation; prevents hardcoded content leaking into components. Revisit condition: once content stabilizes, migrate to build-time typed TS module
- (decision) AD-4 Contact delivery: components depend on a MessageDelivery abstraction (port interface: send(payload) -> receipt); EmailJS is one injectable adapter behind it. Binds vendor isolation; prevents EmailJS SDK types/calls leaking into the Swagger playground component, keeping vendor swap to writing one new adapter
- (decision) AD-5 Topology rendering: pure SVG elements in Angular templates with data bindings for node/edge state; no graph library. Binds topology as fixed 5-node layout; prevents heavyweight deps and keeps outage styling as plain bound classes
- (decision) AD-6 Styling: hand-rolled CSS with global design tokens (CSS custom properties for cluster palette, status colors, monospace stack); component-scoped styles via Angular default style encapsulation. No Tailwind, no component library. Binds theme vocabulary; prevents per-component hardcoded colors diverging from the actuator theme
- (decision) AD-7 Deployment: GitHub Actions workflow on push to main — ng build with project-page base-href (username.github.io/repo/), upload artifact, deploy to Pages. Binds CI/CD; prevents committed build artifacts and manual deploy drift. All asset paths must be base-href-safe
- (version) Angular 22.x (verified 2026-08: latest 22.1.3; TS 6, Node >=22, esbuild builder, signals stable, OnPush default, fetch-based HttpClient default)
- (decision) AD-8 Framework baseline: greenfield Angular CLI v22 project — standalone components, signals-first, OnPush, new control flow (@if/@for), zoneless if default in scaffold. Binds idiom level; prevents mixing legacy NgModule/decorator patterns
- (decision) AD-9 Testing: Vitest via ng test for unit tests — priority on ClusterStateService outage/recovery state transitions and MessageDelivery adapter mocking; E2E deferred (revisit: post-MVP, Playwright smoke on outage flow)
- (decision) Terminal Console: scrollable DOM list bound to logs[] signal in ClusterStateService, capped at last 200 entries
- (decision) Outage engine: pure simulation service emitting scripted event sequences into cluster state; no timers in components
- (decision) AD-10 SimulationEngine is sole writer of outage state; UI controls only invoke engine commands (resolves HALF-OPEN initiator conflict)
- (decision) AD-11 Port/data seams carry typed code-owned contracts: MessageDelivery defines payload+DeliveryReceipt+typed results; canonical content interfaces live in core/data
- (constraint) Derived views are computed selectors in store, store holds raw status. Startup fetch failure renders themed SERVICE UNAVAILABLE retry panel. EmailJS public key in bundle accepted as public-key-by-design constraint
